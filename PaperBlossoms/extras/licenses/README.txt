Some dependency open source libraries are provided with PaperBlossoms. Each is listed 
below, along with the name of its license, the file where its license can be found, 
a desciption of library functionality, and a URL where the library, and its documentation
can be found.

Python: Python Software Foundation License Version 2: Python-LICENSE.txt
Embeds ability to execute programs written in the ubiquitous programming language.
Required by PaperBlossoms.
https://www.python.org/

PyPDF: BSD License: pypdf-lib-LICENSE.txt
Provides reading of PDF files. Required by PaperBlossoms. 
https://github.com/py-pdf/pypdf

PYCA cryptography: BSD License: cryptography-lib-LICENSE.txt
Provides encryption and decryption using standard protocols. Required by PyPDF.
https://github.com/pyca/cryptography

Python C Foreign Function Interface: MIT No Attribution License: Python-CFFI-LICENSE.txt
Provides functions for calling out to C from Python. Required by PYCA cryptography.
https://github.com/python-cffi/cffi

pycparser-lib: BSD License: pycparser-lib-LICENSE.txt
Provides parsing of C language. Required by Python C Foreign Function Interface.
https://github.com/eliben/pycparser
